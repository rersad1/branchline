# Third-party components

Branchline uses dependencies recorded in `backend/Cargo.lock`, `desktop/Cargo.lock`,
`frontend/package-lock.json` and `desktop/package-lock.json`. These include Rust,
Axum, Tokio, Tauri, React, Vite, TypeScript, Tailwind, TanStack Query, Monaco Editor,
xterm and their transitive dependencies. Each component retains its own license
and notices as distributed by its upstream package.

When redistributing application binaries or dependency source, include the applicable
upstream license/copyright notices from the exact locked packages. This source-only
repository does not vendor those packages or transfer their ownership. The bundled
icon is a project-generated runtime asset; no external reference screenshot is included.

No license for the Branchline project itself has been added by this publication.
