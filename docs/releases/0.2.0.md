# Branchline 0.2.0

- Windows notifications now open the exact worktree and agent session when clicked.
- ACP confirmations and OpenCode questions can notify while another worktree is selected.
- Memory diagnostics include per-worktree summaries, pressure data and optional soft budgets.
- Branchline automatically checks GitHub Releases for updates. Open **Обновления Branchline** to download a new version and choose **Сохранить и перезапустить**.
- Update packages are checked against the application's signing key and signed version before installation. Work in Changes is saved before restarting; running terminals and agents are stopped through normal application cleanup.

## Install

Download `Branchline_0.2.0_x64-setup.exe` and run it on Windows 11 x64 with WebView2.
Existing workspace settings are retained. Version 0.1.1 needs this one manual upgrade;
the in-app updater is available starting with 0.2.0.

The Windows installer has no Authenticode certificate. Update signatures (`.sig`)
are separate application signatures used by the built-in updater.

Windows-only projects work without WSL. WSL projects require an explicitly selected
Linux x86_64 environment with the runtime prerequisites in the README. This remains
an early release; the documented provider and platform limits still apply.
