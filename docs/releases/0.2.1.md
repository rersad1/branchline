# Branchline 0.2.1

- Added **Освободить память…** to terminal workspaces. After confirmation, Branchline stops that worktree's managed terminals, agents and their owned child processes. Tabs, order, split and launch choices remain available for an explicit restart.
- Background tasks continue until you choose to stop them. There is no automatic termination after inactivity, and other worktrees and external processes are unaffected.
- Added **Экспортировать сводку** to memory diagnostics: a bounded, streaming JSON summary with observed min/max, timestamps, category totals, session ranges and coverage. The detailed JSONL remains available through **Экспортировать полный журнал**.
- Missing metrics and partial inventories remain explicit. Peaks are measured from simultaneous category totals, and the summary does not add WSL memory to Windows vmmem.

## Update

In Branchline 0.2.0 or later, open **Обновления Branchline**, check for updates,
download 0.2.1 and choose **Сохранить и перезапустить**. Save active work before
restarting: managed agents and terminals are stopped during installation.

For manual installation, download `Branchline_0.2.1_x64-setup.exe` on Windows 11 x64.
Workspace settings are retained. The updater uses the existing application signing
key; the installer does not have a Windows Authenticode publisher certificate.
